⚙️ Site Settings

सामान्य, SEO, sitemap/robots, इंटीग्रेशन, पूर्ण बैकअप व कैशिंग — server/data/site-settings.json

वे सेटिंग्स जो ज़्यादातर CMS डैशबोर्ड में सामान्य / General में मिलती हैं।

📞 संपर्क विवरण (Contact Details)

ये विवरण वेबसाइट, संपर्क पेज, गोपनीयता/नियम पेज और फुटर में दिखेंगे।

Registrar पर support@livehospital.org → ऊपर वाले Gmail पर email forwarding सेट करें। विस्तृत गाइड: deploy/EMAIL_SETUP.md

सोशल मीडिया (पूर्ण URL)

खाली छोड़ें तो फुटर में वह लिंक छिप जाएगा। WhatsApp के लिए ऊपर नंबर या नीचे सीधा लिंक।

दृश्यता (Visibility)

Robots.txt व Sitemap की विस्तृत लाइनें Permalink & फाइलें टैब में सेट करें; वे लाइव /robots.txt व /sitemap.xml पर जाती हैं।

एपीआई व एकीकरण (API & Integration)

Google Analytics 4 (Measurement ID) या Google Tag Manager (Container ID) यहाँ दें; सेव के बाद पब्लिक पेजों पर seo-bootstrap.js स्वचालित लोड करेगा। दोनों भरे हों तो GTM प्राथमिकता लेता है। GA4 ID पाने के लिए: analytics.google.com → Admin → Data Streams → Measurement ID (G-XXXXXXXX)।

ब्राउज़र की साइट सेटिंग (जानकारी)

कैमरा, माइक, लोकेशन, पॉप-अप ब्लॉक या जावास्क्रिप्ट चालू/बंद — ये विकल्प आगंतुक के ब्राउज़र (Chrome, Edge, Firefox) में होते हैं, इस डैशबोर्ड से कंट्रोल नहीं होते। उपयोगकर्ता को साइट की अनुमति ब्राउज़र के पते बार / सेटिंग्स से मिलती है।

हर पेज का Title और Meta Description (Google सर्च स्निपेट)। सेव के बाद पब्लिक पेज seo-bootstrap.js से अपडेट होते हैं।

Permalink (यूज़र-फ्रेंडली URL)

सर्वर पर ये रूट सक्रिय हैं (बिना .html):

  • / — होम
  • /privacy, /terms, /cookies, /contact

साइटमैप व रोबोट्स (लाइव सर्वर चालू हो तब खोलें):

/sitemap.xml  |  /robots.txt

Sitemap — अतिरिक्त पथ (प्रति लाइन, / से शुरू)

Robots — अस्वीकृत पथ (प्रति लाइन)

इमेज SEO: लोगो / मुख्य ग्राफिक्स के लिए वर्णनात्मक alt टेक्स्ट। HTML में मैन्युअल alt="..." जोड़ते समय इन दिशानिर्देशों का पालन करें।

ज़रूरी: डाउनलोड के लिए server फ़ोल्डर से node server.js चालू हो और आप उसी पोर्ट पर खोलें — उदा. http://localhost:5000/admin। VS Code Live Server / सिर्फ HTML फाइल खोलने पर API 404 देगी; कोड अपडेट के बाद सर्वर रीस्टार्ट करें।

पूर्ण बैकअप में server/data/*.json (साइट सेटिंग्स आदि) और MySQL का पूरा डेटा (हॉस्पिटल, डॉक्टर, एडमिन, आदि) एक JSON फाइल में आता है। नई होस्टिंग पर पहले वही Node + MySQL + कोड फाइलें डिप्लॉय करें, फिर यहाँ से अपलोड कर रिस्टोर करें।

⚠️ अपलोड से मौजूदा डेटाबेस पूरी तरह रीप्लेस हो जाएगा। गलत फाइल से पहले डाउनलोड से बैकअप ले लें।

🗑️ Demo / Sample Data हटाएँ

सभी हॉस्पिटल, डॉक्टर, ब्लड रिक्वेस्ट और शहर MySQL से हट जाएँगे। Admin login safe रहेंगे। Live साइट पर पुराना dummy data दिख रहा हो तो एक बार चलाएँ।

स्पीड / कैशिंग: CSS, JS, इमेज आदि पर Cache-Control: max-age=...। HTML पेज हमेशा ताज़ा रखे जाते हैं।
